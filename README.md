## Selected projects

### [GhOstOP Studio](https://github.com/GhOstOP007/GhOstOP-Studio)
A desktop app for organizing travel photos and videos by content or location. Uses local photo classification with CLIP through Transformers.js, plus metadata-based organization.

**JavaScript · Electron · Transformers.js**  
[Source](https://github.com/GhOstOP007/GhOstOP-Studio) · [Windows releases](https://github.com/GhOstOP007/GhOstOP-Studio/releases)

### [Spent Tracker](https://github.com/GhOstOP007/spent-tracker)
A mobile expense tracker with budgets, recurring-subscription tracking, savings goals, and Supabase-backed authentication and synchronization.

**TypeScript · React Native · Expo · Supabase · Zustand**  
[Source & setup](https://github.com/GhOstOP007/spent-tracker)

### [Sorting Visualizer](https://github.com/GhOstOP007/Sorting-Visualizer)
An interactive visualization of Bubble, Insertion, Selection, Quick, and Merge Sort, built to make algorithm behavior easier to follow.

**JavaScript · Next.js · React · Tailwind CSS**  
[Source](https://github.com/GhOstOP007/Sorting-Visualizer)

### [BikeAuto](https://github.com/GhOstOP007/BikeAuto)
An experimental same-phone Android Auto receiver with a bike-focused launcher and setup flow. A documented fork of [Open Headunit](https://github.com/andreknieriem/open-headunit), with upstream attribution, an installable prerelease, and focused automated tests. Physical-device testing is still pending.

**Kotlin · Android · Gradle · JUnit · Robolectric**  
[Source](https://github.com/GhOstOP007/BikeAuto) · [APK & setup](https://github.com/GhOstOP007/BikeAuto/releases/tag/v0.1.0)
